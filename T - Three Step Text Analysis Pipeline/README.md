# Three Step Text Analysis Pipeline

The three steps of the pipeline, one folder each, in running order: [T1 - Text Summarization](<T1 - Text Summarization/Text Summarization Workflow Overview.ipynb>) turns each congressional hearing transcript into one summary; [T2 - Topic Extraction and Stance Analysis](<T2 - Topic Extraction and Stance Analysis/Topic Extraction Workflow Overview.ipynb>) builds the topic codebook from the summaries and extracts each legislator's stance; [T3 - Topic Relevance and Corporate Disclosure](<T3 - Topic Relevance and Corporate Disclosure/Topic Relevance Workflow Overview.ipynb>) scores how close each S&P 500 firm's 10-K business description is to the legislation on one topic. Each step opens with a workflow overview notebook and ends with a running example that follows the same hearing, the Facebook hearing of April 10, 2018. Figures and tables sit under `R - Results` in a folder tree that mirrors this one, and the data sit under the same tree on the scratch root.
